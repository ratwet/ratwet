## 👋 About Me

I’m a **B.Tech Mathematics & Computing student at Central University of Jammu** focused on building practical systems at the intersection of:

**Applied AI · Computer Vision · Robotics · Embedded Systems · IoT**

I enjoy taking a problem from **idea → implementation → testing → measurement → documentation**.

My projects span neural networks, real-time computer vision, ESP32 robotics, IoT telemetry, and embedded control systems. I care about understanding how systems work under the hood rather than treating models and hardware as black boxes.

Currently, I’m mentoring student teams in **ML, computer vision, embedded systems, IoT, and robotics** through the CSE technical club in partnership with **e-Yantra**.

* Practical ML engineering

## 🚀 Featured Projects

### 🥇 RoboTraverse

**Rope-traversing racing robot**

> **1st Place — CSE Robotics Club Challenge**

A high-speed rope-traversing robot built around an ESP32 and BLDC motor.

**Performance**

`10 m in 2.16 s`
`4.63 m/s`
`16.6 km/h`

**Stack**

`C++` · `ESP32` · `BLDC` · `Bluetooth Serial`

[View Repository →](https://github.com/ratwet/RoboTraverse)

---

### ⚽ Wi-Fi Controlled Soccer Robot

A competitive **4-wheel robotic platform** controlled entirely through Wi-Fi.

The robot exposes a browser-based virtual gamepad, allowing control directly from a web browser without installing a dedicated application.

**Hardware**

* ESP32
* Dual L298N motor drivers
* BO geared motors
* 4-wheel drive

**Stack**

`C++` · `ESP32` · `L298N` · `Wi-Fi`

[View Repository →](https://github.com/ratwet/esp32-soccer-robot)

---

### 🖐️ Gesture-Based Cursor Control

A real-time computer-vision application for controlling the mouse cursor using hand gestures captured from a webcam.

**Highlights**

* Real-time hand tracking
* Gesture-based cursor interaction
* No physical mouse required
* MediaPipe landmark detection
* Wayland-native Ubuntu implementation

**Stack**

`Python` · `OpenCV` · `MediaPipe`

[View Repository →](https://github.com/ratwet/gesture-cursor-control)

---

### 📡 IoT Device Simulator

An ESP32-based edge-device simulator that periodically collects and transmits telemetry.

**Simulated telemetry**

* Environmental measurements
* GPS movement

* Periodic MQTT transmission

**Update interval**

`10 seconds`

**Stack**

`ESP32` · `DHT22` · `MQTT` · `Wokwi`
